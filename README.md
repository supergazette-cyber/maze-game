# 격자 탈출 (maze-game)

방향키로 미로를 빠져나가는 단일 HTML 게임. 빌드 도구나 의존성 없이 [`maze.html`](maze.html) 파일 하나를 브라우저로 열면 바로 실행됩니다.

## 플레이 방법

좌상단 파란 커서에서 출발해 우하단 앰버색 지점에 도착하면 클리어입니다.

| 조작 | 키 |
| --- | --- |
| 이동 | `↑` `↓` `←` `→` 또는 `W` `A` `S` `D` |
| 이동 (모바일) | 화면을 밀어서 스와이프, 또는 하단 D-패드 |
| 새 미로 | `R` |

## 기능

- **미로 생성** — 재귀적 백트래킹(iterative backtracker)으로 매 판 새로 생성하며, 출발점에서 도착점까지의 경로가 항상 정확히 하나인 완전 미로를 만듭니다.
- **난이도 3단계** — 쉬움 11×11 / 보통 17×17 / 어려움 25×25
- **기록** — 소요 시간과 이동한 칸 수를 재고, 난이도별 최고 기록을 `localStorage`에 저장합니다.
- **경로 표시** — 지나온 칸이 옅게 칠해져 왔던 길을 되짚을 수 있습니다.
- **다크 모드** — 뷰어의 테마를 따라가며, 캔버스 색도 CSS 토큰에서 읽어 함께 전환됩니다.
- **반응형** — 데스크톱과 모바일(약 400px) 모두 대응합니다.

## 색상

색상은 모두 `maze.html` 상단 `:root` 블록의 CSS 변수로 모여 있습니다.

| 토큰 | 라이트 | 다크 | 용도 |
| --- | --- | --- | --- |
| `--cursor` | `#10218B` | `#7B88F0` | 플레이어 커서 (Epson Blue, Pantone 287) |
| `--cursor-soft` | `rgba(16,33,139,.13)` | `rgba(123,136,240,.17)` | 지나온 경로 |
| `--goal` | `#D97534` | `#EE9A54` | 도착 지점 |
| `--accent` | `#177F73` | `#3FBFAE` | 버튼·난이도 칩 |
| `--wall` | `#2A3240` | `#4A566B` | 미로 벽 |

다크 모드 값은 같은 색상각을 유지한 채 명도만 올린 것으로, 어두운 바탕에서의 대비를 확보하기 위한 값입니다.
